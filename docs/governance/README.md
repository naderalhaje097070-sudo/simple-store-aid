# Mongezz Engineering Governance

Start with the current repository state and decisions:

1. `PROJECT_STATE.md`
2. `DECISIONS.md`
3. `TASKS.md`
4. `AGENTS.md`

Select the delivery framework:

- `NAADF.md` for new projects or independently designed subsystems.
- `NAADF-CMF.md` for changes to the existing Mongezz application.

Supporting policies:

- `DELIVERY_PROTOCOL.md`
- `SECURITY_BASELINE.md`
- `DATABASE_CHANGE_POLICY.md`
- `TESTING_POLICY.md`
- `REVIEW_PROTOCOL.md`

These documents define the engineering process. Source code, migrations, tests, approved specifications, and project-state files remain the factual source of truth for implementation behavior.
