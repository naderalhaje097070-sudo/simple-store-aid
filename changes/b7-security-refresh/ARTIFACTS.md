# Evidence preservation

INDEX.json records every included file SHA256 and raw native ZIP metadata. The archive bytes are checked against GitHub artifact digests before extraction and Git blob hashes on publication. Raw failed results remain failed; metadata source/run/event/attempt is preserved.

The first7-advisory audit, first whole-lock preparation, initially failed body-parser comparison, later two-advisory audit, failed official-parent import-shape preparation, successful deterministic parent/qs preparation and final current-source acceptance remain separate evidence. Extracted code snapshots stay inside raw archives rather than creating an unreviewed protected-source copy. Representative sanitized JSON receipts are included for inspection.

No native run is attributed to the eventual documentation-only evidence delivery. Its inheritance of a tested source requires exact protected-path, blob/mode, both manifest and all SQL preservation, plus independent publication review. These are separate from GitHub branch protection requirements, which the connector cannot read (403).
