## الهدف
إنشاء صفحة رئيسية تسويقية (Landing) لمنجز تظهر للزوار غير المسجلين على المسار `/`، مع تحويل المستخدمين المسجلين تلقائياً إلى `/app`.

## التغييرات

### 1. تعديل `src/routes/index.tsx`
- إزالة الـ redirect المباشر إلى `/auth` للزوار.
- إبقاء redirect إلى `/app` للمستخدمين المسجلين فقط (فحص الجلسة client-side مع `ssr: false`).
- عرض صفحة Landing كاملة للزوار.
- إضافة `head()` بـ title, description, og:title, og:description, canonical.

### 2. أقسام الصفحة (RTL، عربي، mobile-first)
1. **شريط علوي خفيف**: شعار "منجز" + زر "دخول" + زر "ابدأ مجاناً" (يقودان إلى `/auth`).
2. **Hero**: 
   - عنوان: "دفتر ذكي لمحلك الصغير"
   - وصف: "بِع، حصّل، تابع ديون عملائك وعهدة المندوب — كل شي في مكان واحد، بدون تعقيد."
   - زرّان: "ابدأ مجاناً" (أساسي) + "سجّل دخول".
   - بطاقة معاينة بصرية بسيطة (mockup CSS — لا صور خارجية) تحاكي شاشة "البيع السريع".
3. **المزايا** (4 بطاقات بأيقونات lucide):
   - بيع سريع — "أصدر فاتورة كاملة بأقل من 10 ثوانٍ."
   - ديون العملاء — "اعرف من عليه كم، وحصّل بثقة."
   - عهدة المندوب — "تابع ما خرج وما رجع، بدون لخبطة."
   - تسويات يومية — "أقفل يومك بضغطة، واعرف ربحك الحقيقي."
4. **كيف يعمل** (3 خطوات مرقّمة):
   - اشترك بحسابك.
   - أضف منتجاتك وعملاءك.
   - ابدأ البيع والمتابعة من جوالك.
5. **FAQ** (4 أسئلة): هل هو مجاني للتجربة؟ هل يعمل بدون نت؟ هل بياناتي آمنة؟ هل أحتاج خبرة محاسبة؟
6. **Footer**: شعار، حقوق، روابط (الدليل، تسجيل دخول).

### 3. الطابع البصري
- يستخدم نفس tokens الموجودة في `src/styles.css` (primary, background, muted, card).
- بطاقات بحواف منحنية ناعمة، ظلال خفيفة، فواصل بألوان `border`.
- لا hardcoded colors، لا hex، لا tailwind ألوان مباشرة (`bg-white`, `text-black`).
- خط Tajawal/Cairo الحالي للمشروع.
- صور: لا تُستخدم — Mockup عبر CSS فقط لتفادي placeholder.

### 4. SEO
- `title`: "منجز — دفتر ذكي لمحلك الصغير"
- `description`: تسويقي عربي مختصر <160 حرف.
- `canonical`: `https://simple-store-aid.lovable.app/`
- `og:type: website`, `og:title`, `og:description`, `og:url`.

## ما لن يتغير
- `/auth`, `/app`, `_authenticated/*` تبقى كما هي.
- لا تعديل على Supabase أو قاعدة البيانات.
- لا backend جديد.
