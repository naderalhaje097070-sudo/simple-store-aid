# خطة: تحصيل اشتراكات منجز عبر Paddle

## الهدف
تفعيل **Paddle** كبوابة دفع لاشتراكات التجار في منصة منجز نفسها (التاجر يدفع شهرياً/سنوياً مقابل استخدام التطبيق). Paddle يتولى الضرائب والامتثال في كل دول العالم كـ Merchant of Record (5% + 50¢ لكل عملية، شامل كل الرسوم).

## ما سيتم بناؤه

### 1. تفعيل Paddle على المشروع
- ربط Paddle بـ Lovable Cloud (يُنشأ حساب Sandbox مباشرة للاختبار بدون فلوس حقيقية).
- التحقق من الحساب لاحقاً لتفعيل المدفوعات الحقيقية.

### 2. خطط الاشتراك (Pricing Plans)
محتاج منك تأكيد الخطط قبل إنشائها. اقتراح مبدئي:

| الخطة | السعر | المميزات |
|------|-------|---------|
| **Starter** | $9/شهر | فرع واحد، حتى 500 فاتورة/شهر |
| **Pro** | $19/شهر | فروع غير محدودة، مناديب، تقارير متقدمة |
| **Yearly Pro** | $190/سنة | خصم شهرين |

> ⚠️ لو عندك خطط مختلفة (بالدينار الليبي مثلاً) قولي قبل التنفيذ.

### 3. ربط الاشتراك بالـ Tenant
- إضافة حقول للجدول `tenants`: `subscription_status`, `subscription_plan`, `paddle_customer_id`, `paddle_subscription_id`, `trial_ends_at`, `current_period_end`.
- منح كل tenant جديد **فترة تجريبية 14 يوم** تلقائياً.

### 4. صفحة الباقات داخل التطبيق
- صفحة `/billing` تعرض الخطة الحالية، الفاتورة القادمة، وزر "ترقية".
- زر "اشترك الآن" يفتح Paddle Checkout Overlay.
- في حالة انتهاء التجربة بدون اشتراك، عرض Modal يمنع الوصول للعمليات المالية مع زر للترقية.

### 5. Webhook لتحديث حالة الاشتراك
- نقطة عامة `/api/public/paddle-webhook` تستقبل أحداث Paddle (subscription.created/updated/canceled, transaction.completed).
- التحقق من توقيع Paddle قبل أي تحديث.
- تحديث `tenants.subscription_status` تلقائياً.

### 6. حماية الميزات (Feature Gating)
- Middleware يتحقق من `subscription_status` قبل السماح بإنشاء فواتير جديدة لو الاشتراك منتهي.
- التقارير القديمة وعرض البيانات يفضلوا مفتوحين (لا نقفل بيانات التاجر).

## ملاحظات تقنية
- المنطق المالي الحالي (RPCs، RLS، إقفال اليوم) لن يُمَس.
- جدول جديد `subscription_events` لتخزين سجل أحداث Paddle (audit trail).
- كل عمليات Paddle عبر Lovable's seamless integration (لا تحتاج مفتاح API يدوي).
- بعد التفعيل، Lovable Cloud يحقن المفاتيح تلقائياً في الـ server functions.

## خارج نطاق هذه الخطة
- تحصيل التاجر من زبائنه أونلاين (بطاقات في المتجر) — يحتاج بوابة ليبية محلية، نناقشها لاحقاً لو احتجت.
- فواتير ضريبية محلية بالعربية (Paddle يصدر فواتير إنجليزية تلقائياً).

---

**أكد لي:**
1. الخطط والأسعار المقترحة مناسبة؟ ولا عندك أسعار محددة؟
2. فترة تجربة 14 يوم OK؟
3. لما الاشتراك ينتهي: نقفل إنشاء فواتير جديدة فقط، ولا نقفل كل شيء؟
