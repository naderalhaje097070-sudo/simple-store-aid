# Security

Preserve existing signature/issuer/audience/OAuth-client policy and validated build/runtime configuration.
Exact-loopback UID firewall/native redirect preflight before credentials, preload in real app process,
post-bundle IPv4/IPv6 and fetch counters zero. No service-role key in app environment.
Crypto helper verifies fixed local JWKS, signed actor/client/issuer/audience before interpreting iat/exp/session.
Token digest/session IDs remain in memory; artifacts expose equality booleans and allowlisted timestamps only.
Raw JWTs/passwords/refresh/id tokens/authorization code/verifier are collected for no-leak scans.
Reuse evidence quarantine before upload. No raw auth error/payload/exception serialized.
MCP expired requests require no downstream user/tool calls and independently proven exp error for same token.
This does not certify production runtime/proxy/nonempty data isolation.
