## سبب العطل والتغيير

المصادقة المولدة تتحقق من JWT، بينما يحتفظ إغلاق الحساب بهوية Auth ورموز صالحة. لذلك كانت وظيفة السعر تصل إلى البوابة بعد الإغلاق.

أُضيف المساعد غير المولد `src/lib/account-state.server.ts`، واستدعاؤه أولًا داخل handler في `src/utils/payments.functions.ts`. ينتظر الفحص بعد المصادقة وقبل `gatewayFetch` وقراءة أسرار المزود.

يستخدم `context.supabase` بالرمز نفسه لاستدعاء `current_tenant_id` القائم. تعريفه الفعلي ينفذ `assert_active_actor` قبل إعادة معرف متجر قابل لـnull. اكتمال هذا الحكم هو الدليل؛ قيمة المتجر غير مستخدمة عمدًا، دون إضافة شرط دور أو متجر.

الرفض المحدد `42501/account_inactive` يعود `account_inactive`. أي خطأ آخر أو استثناء أو تعذر نقل أو مهلة يعود `account_state_unavailable`. المهلة 3 ثوانٍ مع abort وتنظيف المؤقت، حتى لو لم يستقر النقل. لا cache أو سماح افتراضي.

ملفا المصادقة المولدان و`paddle.server.ts` والترحيلات الـ45 والعقود المالية محفوظة حرفيًا. لا تغيير للأسعار أو الاشتراكات أو webhooks أو UI. عقد GET ومدخل `priceId/environment` والترميز والنتيجة الأولى و`Price not found` محفوظة للحساب النشط.

## البيئة والعزل والبيانات

Supabase CLI2.101.0 محلي داخل runner مؤقت، مع Node22 وBun1.2.14 وسلسلة الترحيلات الـ45. الاختبار استخدم معرف الوظيفة الذي ولده بناء التطبيق وبروتوكول TanStack الحقيقي؛ لم يستورد handler أو يستبدل المصادقة.

ملف Node preload داخل tests فقط يستبدل GET لعنوان بوابة السعر الموجود ومعرفات وهمية محددة، مع اعتمادات وهمية ثابتة وعدّاد. لا تعديل لعنوان الإنتاج أو مفتاح تفعيل داخل src، ولا اتصال بـPaddle، حتى sandbox.

UID firewall منع الخروج غير المحلي، مع canary بلا اعتمادات قبل قراءة المفاتيح. بعده بقي عداد رفض IPv4 عند 2→2 وIPv6 عند صفر، وexternal fetch غير المستبدل صفر. هذا احتواء لعملية التطبيق المختبرة؛ لا تدقيق لخروج جميع خدمات المزوّد.

استُخدمت fixtures لهوية Auth والمتجر والملف والدور فقط، دون منتجات أو طلبات أو دفعات أو تدقيق مالي. بصمات public22 وحالة Auth المحددة `id/deleted_at/banned_until` قبل/بعد مطابقة، وحدث إغلاق خاص واحد. إصدار الرموز والجلسات يغير حالته الطبيعية؛ لا ندعي ثبات كل Auth/session rows أو منع تسجيل دخول Auth.

نجح فحص الأسرار والتنظيف 3/3: ملف الاعتمادات وعمليات التطبيق وحاويات البيئة. لا بيانات أو اعتمادات إنتاج.
