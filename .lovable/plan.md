# تصدير فاتورة PDF / منجز

## الهدف
إتاحة تحميل وطباعة الفاتورة من شاشة "تفاصيل الفاتورة" بصيغة PDF عربية RTL مناسبة للجوال (إيصال A5).

## التغييرات

### 1. مكتبة PDF
- إضافة `jspdf` فقط (خفيفة، تعمل في المتصفح، لا تحتاج backend).
- لدعم العربية الصحيحة سنرسم النص عبر `html2canvas` لقالب HTML مُعدّ مسبقاً ثم نحوّله لـ PDF — يضمن أن الحروف العربية تظهر متصلة وبخط النظام بدون مشاكل تشكيل.
- إضافة: `bun add jspdf html2canvas`.

### 2. مكوّن جديد `src/components/InvoicePrintable.tsx`
قالب HTML مخفي (off-screen) يُبنى لحظة الطلب ويحتوي:
- **الترويسة**: اسم المحل (من `tenants.name`) + رقم الفاتورة + التاريخ والوقت.
- **الأطراف**: اسم العميل (إن وُجد) + اسم المندوب (إن كانت توصيل مندوب).
- **جدول الأصناف**: اسم / كمية / سعر الوحدة / الإجمالي (د.ل، أرقام LTR).
- **الملخص المالي**: الإجمالي، المدفوع للصندوق، بيد المندوب (للفواتير المندوب)، المتبقي، طريقة الدفع، الحالة.
- **ذيل**: "شكراً لتعاملكم مع {اسم المحل}" + ملاحظة "هذه فاتورة غير ضريبية".

### 3. أزرار في شاشة تفاصيل الفاتورة (`src/routes/_authenticated/app.tsx`)
داخل `InvoiceDetailsScreen` أسفل الملخص:
- **زر "تحميل PDF"** → يبني القالب، يحوّله canvas → jsPDF → `doc.save("invoice-{number}.pdf")`.
- **زر "طباعة"** → يفتح `window.print()` على نفس القالب (CSS `@media print` يخفي بقية الواجهة).
- حالة loading أثناء التوليد + toast نجاح/فشل.

### 4. ستايل الطباعة
- إضافة قواعد `@media print` في `src/styles.css`:
  - إخفاء `.no-print` (الـ shell، الـ sidebar، الأزرار).
  - إظهار `.print-only` (قالب الفاتورة).
  - حجم الورق A5 + هوامش 10mm.

## ملاحظات تقنية
- لا تغييرات في قاعدة البيانات أو RPC.
- كل البيانات متاحة فعلياً عبر `useInvoices` + `useTenant` + `useCustomers` + `useCouriers`.
- اتجاه RTL في القالب يُضبط بـ `dir="rtl"` + `font-family` عربي افتراضي (Tahoma fallback لضمان وضوح الحروف في canvas).
- صيغة المبالغ تستخدم نفس `formatLYD` المستعمل حالياً في الواجهة.

## خارج النطاق
- لا QR code، لا شعار محل (يمكن لاحقاً عبر رفع صورة في الإعدادات).
- لا إرسال WhatsApp مباشر — فقط حفظ/طباعة.
