2.120.0 دون قاعدة بيانات؛ اختبارات التشغيل تستخدم CLI 2.101.0 القائم. بقيت الترحيلات
الـ44 السابقة وتعريفات العمليات المالية وتوقيعاتها وصلاحياتها دون تعديل.

يسجل الإغلاق في جدول خاص بمفتاح المستخدم ومرجع Auth من نوع RESTRICT. الجدول محمي
بـRLS ودون صلاحيات كتابة للعملاء. حاجز النشاط القائم يرفض هوية لها سجل إغلاق، ومدخل
`close_owner_account()` بلا معاملات يغلق حساب المتصل المالك وحده. يفحص حالة Auth
الحالية والملكية والدور الحقيقيين، ثم يحفظ حدثًا واحدًا في معاملة واحدة مع قفل صف Auth.

تكرار الطلب يعيد حالة ثابتة دون حدث أو أثر مالي إضافي، ولا يتجاوز حظرًا أو هوية محذوفة.
لا حذف أو فك ملكية أو إلغاء اشتراك أو إعادة فتح أو واجهة جديدة. الحدث الخاص نفسه أثر
تدقيق الإغلاق؛ السجل المالي العام لا يتغير. سياسة مدة الاحتفاظ والمحو ما زالت منفصلة.
