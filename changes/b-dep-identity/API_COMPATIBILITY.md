# API compatibility
No financial RPC, data schema, return contract, valid tool argument schema, OAuth audience, billing/provider policy or generated API route changes. MCP POST bodies now have explicit limits:65536 bytes,256 combined array/object members, object/container depth32 and5s read deadline. Oversize/structure413, malformed/aborted400 and read deadline408 contain fixed nonlogging errors. Valid bodies are forwarded byte-for-byte with original headers/signal. Actual source-linked entry placement and native missing-bearer tests cover this batch. Complete authenticated SDK initialize/list/call/invalid-tool contracts on the composed B50 runtime remain required in B5/B6. Non-MCP requests remain the original object.
